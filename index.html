Стратегия оптимизации проекта

Value Engineering для завода DCDA-технологии в СЭЗ «Атырау» без снижения безопасности и экологических стандартов

Технологическое решение зафиксировано: Технология DCDA (Double Contact Double Absorption) — единственный обоснованный выбор для feedstock из элементарной серы ТШО. Конверсия SO₂ ≥ 99,7%, выбросы <0,5 кг/т H₂SO₄ — соответствуют EU BAT BREF LVIC. Дополнительная опция: блок утилизации тепла (WHR) — генерирует электроэнергию из тепла реакции для продажи в сеть. Все рекомендации — оптимизация ВНУТРИ выбранной технологии.

1Технологический инжиниринг

  • 4-проходный конвертер вместо 5-проходного — соответствует требованиям МЭГПР по SO₂ без избыточного резерва
  • Параметры пара котла WHR: 3,0–3,5 МПа вместо 4,0 МПа — снижает металлоёмкость при сохранении мощности
  • Резервуарный парк H₂SO₄ — сократить при наличии LOI с «Казатомпромом» (take-or-pay)
  • Hybrid modularization: ядро — традиционный монтаж; вспомогательные системы — prefab skids из Китая
  • DCS/SCADA: Supcon / Hollysys (SIL2) вместо Siemens/Honeywell — экономия $1,5–3,5M

2WHR — утилизация тепла → электроэнергия

  • В процессе DCDA выделяется ~3,0–3,2 ГДж тепла на тонну серы — тепло необходимо отводить в любом случае
  • Установка паровой турбины монетизирует неизбежный тепловой поток: нетто-экспорт 23–69 МВт в зависимости от мощности завода
  • При тарифе $30/МВт·ч дополнительная выручка: $5M/год (50к т серы) → $15M/год (150к т серы)
  • Payback турбины (сверх стоимости альтернативной градирни) — 1,5–2,5 года
  • Поставщики: Triveni Turbines (Индия), BHEL или китайские аналоги — $5–15M vs. $12–20M (Siemens/MHI)

3Закупки и sourcing

  • EPC-цена фиксируется ПОСЛЕ завершения FEED — снижает contingency с 15% до 8–10%
  • Конкурентный тендер среди 3–4 китайских EPC — конкуренция снижает цену на 10–20%
  • Open-book accounting: JV видит реальные закупочные цены; EPC-маржа ограничена cap
  • Сертифицированное б/у — только для некритичного вспомогательного оборудования (API 610)

4Гражданское строительство

  • Геотехнические изыскания до выдачи задания на фундаменты ($300K) — экономия $2–5M
  • Компактный генплан: технологическая цепочка в одну линейную ось
  • Кабельное хозяйство — подземные каналы дешевле эстакад в климате Атырауской области
  • Выбор участка СЭЗ у магистрали КТЖ — минимальная длина подъездного пути

5Управление проектом

  • Lump Sum EPC после FEED — единственная модель, защищающая JV от перерасхода
  • Независимый Owner's Engineer нанимается ДО начала FEED — ROI 10:1
  • Performance Bond от EPC-подрядчика: 10% от суммы EPC
  • Гражданское строительство — через местных субподрядчиков (local content)
  • EVM (Earned Value Management) — еженедельная отчётность с Месяца 16

6Стандарты безопасности

  • EU BAT BREF LVIC — конверсия SO₂ ≥99,7%, выбросы <0,5 кг/т: выполняется на 4-проходном DCDA
  • IEC 61511 (SIL2) — требование к DCS/SCADA сохранено
  • API 610 / API 682 — требования к насосам не снижаются
  • Экокодекс РК 2021 — все нормы по SO₂, туману H₂SO₄, стокам соблюдены
  • ОПО I класса: регистрация в ДЧС, страхование ОПО, ПЛАС — обязательны
